Maturity / Depth Axis — CISEM-VOC-00003 (LIVE, DIOS 0014)
  • −8 Maturity Levels — Signal → Constitutionalsemantic depth, distinct from structural depth_level
    • ·0 · Signal— should this be investigated? → IBD raw capture. Validation to reach: none (capture-first).
    • ·1 · Observation— what happened? → DRAFT / PARKED. Validation: documented + traceable.
    • ·2 · Hypothesis— could this be true? → PROPOSED. Validation: testable statement.
    • ·3 · Pattern— does it recur? → (recurring finding). Validation: ≥2 real observations.
    • ·4 · Insight— why does it matter? → DRAFT-of-topic. Validation: actionable understanding.
    • ·5 · Principle-Candidate— could it guide decisions? → CONSENSUS-REACHED. Validation: Opus soundness (independent).
    • ·6 · Validated-Principle— can we rely on it? → PROVISIONAL-ACTIVE / LIVE. Validation: mechanism exists + runs (I23).
    • ·7 · Constitutional— should descendants inherit it? → RATIFIED (foundational). Validation: Governor decree + inheritance.
