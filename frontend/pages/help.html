How to use the CISEM Living Index.

Opening the index

Double-click frontend/index.html in your file explorer. No server required — it opens directly in your browser via file://.

Navigation

  • Click CISEM (top-left) to return to the home index at any time.
  • Hover Index ▼ to reveal all 20 groups in a dropdown. Click any group to jump to its page.
  • Click ✎ (top-right) to open the “To Be Reviewed & Created” page.
  • Click ? (top-right) to open this help page.
  • Use your browser’s back/forward buttons for history navigation.

Searching

Every group page has a search bar at the top. Type to filter the file list in real-time. The counter shows how many items are visible. Clear the field to reset.

File links

Every link on a group page points to a real file in the CISEM repo (verified against the filesystem). Clicking a link opens the file in your default viewer for that file type (.md, .yaml, .sh).

Links use relative paths from the frontend/ directory. If files have moved, links will 404 until this index is rebuilt.

Keeping the index current

This index is static. When new files are added to the repo, re-run BP-0004 (or its successor) to update the group pages. The To Be Reviewed & Created page lists upcoming work that will expand this index.
