Axioms

Core Axioms A1–A8 (the eight laws governing every CISEM creation) and Creation Doctrine D1–D6 (how ratification, prevention, and oversight work together). SSOT: CISEM-FOUND-00001; always-loaded mirror: CLAUDE.md §2.4–§2.5.

Core Axioms — A1–A8
  • A1
    Nothing stands alone
    No orphans, no islands — everything connects. Every artifact has at least one explicit relationship to the rest of the system. References that cannot resolve are a violation (I1). Enforced by: Island Detection + Cross-Boundary Zero-Context.
  • A2
    Everything is part of a corespine
    Every artifact declares its governing corespine (Schema_anchor + Core_spine fields). No artifact may exist outside a corespine. Enforced by: §3.2a gate — corespine declaration is mandatory before creation.
  • A3
    Nothing exists without a place in the schema
    No floating or un-placed element. Every node has an assigned position in the CISEM schema (ARCH-00008 position + SCHEMA-00001). An artifact without a schema place is a violation.
  • A4
    Nothing is implemented without a ratified plan
    No ad-hoc building. The flow is: plan → ratify → implement. A ratified plan is mandatory for every governed creation (I25). The only exemptions are IBD raw-capture and SWIFT-safe zero-blast extractions (ARCH-00190 §7). "Small / safe / dogfooding" is NOT an exemption — Governor decree 2026-07-18.
    I25 ENFORCED
  • A5
    EVERYTHING is created via hardcoded protocol
    Files, documents, agents, skills, wizards, vocabulary, file-naming, QC of every type, changes to hardcoded elements, core councils — NO category is exempt from the §3 gates. Creating any of these without the gates is a violation (I15).
  • A6
    Context-focus over rigidity
    Act with context focus; stay aware of the limits and dangers of rigid interpretation. Hardcoding is a respectful guardian, not a cage (D6). It fixes what was ratified and frees everything else. Rigidity is a failure mode, not a virtue.
  • A7
    Constant self-improvement via an AI expert team
    A brilliant holistic team of top-AI-expert pockets (the RQC — ARCH-00320 §6) oversees and critiques how CISEM works and finds PERMANENT improvements, presenting conclusions for human processing and ratification. A4 gates the implementation of any improvement.
  • A8
    One Source (SSOT / Consolidation)
    Every concept, rule, and node has exactly ONE authoritative home registered in dna/ssot-registry.yaml. Related content CONSOLIDATES into that hub — never duplicates or forks. A mirror may summarize or reference but may NOT diverge from its source. On conflict, the SSOT wins. Governor-decreed 2026-07-18 (I10 one-home + I19 no-duplication).

Creation Doctrine — D1–D6
  • D1
    Ratified = Recurring
    What the Governor ratified happens the same way every time. Fidelity to ratified truth is the guardian's first duty. Every governed creation re-runs the same §3 gates — no special-casing.
  • D2
    Guard boundaries, not paths
    Hardcode WHAT must stay true (invariants), never HOW to get there. Fixed ends, free means. This is what stops stability from becoming rigidity. The invariant set constrains; the creative path inside those constraints is free.
  • D3
    Prevention is permanent + cumulative
    Every unwanted outcome becomes a standing invariant (I1..In, ARCH-00320 §4). The set only GROWS — removing one requires a foundational decree. This is the system's immune memory. Each new session inherits all prior preventions.
  • D4
    Enhancement is permanent + named
    Every wanted behavior is written INTO the creation protocol (ARCH-00230) so AI is reminded AT creation time — never left to memory. An enhancement not baked into the protocol is not permanent.
  • D5
    The guardian audits itself
    Hardcoding ACTIVATES AI oversight: the Recurring Quality Cycle (ARCH-00320 §6) audits every creation and learns from each. Stability and self-evolution are ONE loop, not two forces. Every creation feeds the improvement loop (A7).
  • D6
    Polarity, not contradiction
    Stable-and-evolving are complementary poles, not opposing forces. Hold ratified truth firm while letting all else adapt. Lose the stable pole → drift; lose the evolving pole → ossify. The balance IS the design (A6).
