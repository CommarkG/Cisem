Corespine Routing — Axis 3 (distinct from Placement)

Every governed element carries THREE distinct axes (A9 — each singly-homed, not a rewrite of the others): Axis 1 base Node-DNA fields (ARCH-00008, Sections I–X, tree below) · Axis 2 PLACEMENT — where a node sits in the T-SYS/T-DOM schema tree (hierarchy above) · Axis 3 CORESPINE-ROUTING — which corespine GOVERNS a given artifact, independent of where that artifact is placed. Placement answers “where does it sit”; corespine routing answers “who governs it” — a page can sit under T-SYS while being governed by CS-FRONTEND-001, for example. The tree below reads real Governed Artifacts / content_location data straight from corespine-registry.yaml and the CS-FRONTEND-001 manifest — nothing invented.
