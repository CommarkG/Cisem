Implemented Claude Code skills (.claude/skills/) — slash commands the Governor invokes directly in the Claude Code IDE. Each skill is a self-contained executor: it bootstraps its own CISEM context, runs the §3 gates, and returns a governed artifact. Governed by: CS-AI-BEHAVIOR-001.

    cisem-plan — Plan Wizard
    Runs the ARCH-00190 planning domain protocol to produce a Governor-ratifiable plan. Guides through: goal statement, corespine declaration, Existing-First search, Core-vs-Instance judgment, Pocket Declaration, naming + ID allocation, per-phase state tracking, independent verifier assignment. Returns a draft plan ready for Opus soundness review. Trigger: /cisem-plan in Claude Code IDE.

Trigger: /cisem-meta in Claude Code IDE.

  • /cisem-create
    cisem-create — Creation Wizard

Produces the node file and registers the ID. Trigger: /cisem-create in Claude Code IDE.
