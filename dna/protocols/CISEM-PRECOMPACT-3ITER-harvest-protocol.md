# Pre-Compact 3-Iteration Harvest Protocol (permanent; enhances ARCH-00370)

**Governor decree 2026-07-23.** Every boundary (compact / tab-switch / handoff) fires THREE passes, in order.
Hardwired = the pre-compact hook (`.claude/hooks/pre-compact.sh`, CAL ARCH-00390) MANDATES all three; the
weekly evolve session (RIPL weekly-batch, ARCH-00406) MECHANICALLY processes what they route. Model-performed
on the cue, mechanically gated (honest ceiling — same as A10/ARCH-00370).

## ITERATION 1 — AI-DEFAULTS
Extract every AI-default *failure pattern* the session exposed (the named biases). Examples this session:
consensus-theater/harmonizing · re-derivation (RI-0021) · premise-staleness (RI-0023) · gather→synthesis drop
(RI-0022) · plan-gate-evasion via DRAFT (RI-0020) · Existing-First-as-stop-sign (RI-0024) · deferral-as-caution ·
documentation-as-progress · agreeableness/tone-as-authorization.
→ ROUTE each to `root-insights.yaml` (RI) + the persona self-catch, with a **status** (NAMED / WIRED).

## ITERATION 2 — INTENTS · NUANCES · INSIGHTS (A10 full-fidelity)
Capture the session's FRUITS richly (never flattened): Governor intents + verbatim words · decisions +
reasoning · `[[CORE-SEED]]`s · nuances · the LATEST decisions/definitions with special weight. Home:
the dated `session-harvest-YYYY-MM-DD.md` + `session-learning-index.yaml`.

## ITERATION 3 — PROCESSING & MECHANICAL ENFORCEMENT (the actionable half — the point of the protocol)
For EVERY item from Iter-1 + Iter-2 — **including every parked item** — produce a row with ALL of:
1. **Route** — the existing home it enhances (A8/RI-0024: enhance, never fork).
2. **Status** — WIRED · NAMED · PARKED · DECREED-NOT-YET-WIRED (truth-bearing; Opus stamps WIRED).
3. **Mechanical path to value** — the concrete check/hook/gate that will turn it from idea → measurable
   value, and the WEEKLY-EVOLVE step that drives it there. Parked ≠ dropped (A10-extended: parking ≠ losing);
   a parked item still carries its route + a re-open trigger.
4. **Measurable-value test** — what observable change proves it produced value (COMPLETED-vs-DONE: activation ≠ impact).
**Invariant:** no item leaves Iter-3 un-routed or without a status. The ENHANCE-INDEX (see
`session-harvest-2026-07-23.md` §B) is the reference shape.

## ITERATION 4 — MANDATORY BRAIN REPORT (Governor decree 2026-07-23; fires every pre-compact)
Produce ONE self-contained copyable block for Brain (private repo — carries its own state), covering: WIRED/DONE
fruits · the ENHANCE-INDEX (named-not-wired backlog) · the meta-diagnosis + current ruling · what's still open
for Brain+Governor · git HEAD + [ZF] state. This is the cross-boundary sync so the external colleague stays
aligned with git after every compaction. Format = presentation-preferences (one block). Precedent: the
2026-07-23 report. **Mandatory each time — never skipped.**

## WEEKLY EVOLVE SESSION (the enforcement destination)
The RIPL weekly-batch (ARCH-00406 Phase 1) + freshness axis + accountability board process the Iter-3 rows:
cluster → judge → wire-or-re-park → measure value → mark WIRED. This is where "named" becomes "real."
