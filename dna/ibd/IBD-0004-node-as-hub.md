# OPUS CONCLUSIONS (a first-draft-of-a-topic — NOT a plan)
**The unifying model: NODE-AS-HUB (= the "Gem" / central concentration node).**
Every node IS the persistent SSOT hub for its topic, structured as a mini-tree (ARCH-00330):
- **Root-index** = the node's ESSENCE, consolidated (identity, goal, position, current state).
- **On-demand sub-files** (materialize only when needed — NOT forced on small nodes):
  · PART{NN} — its content parts (size-gate split)
  · DISCUSSION — persistent, APPENDED each time (reused, never recreated — answers "same tree each time")
  · VERSIONS — raw→processed history (BP-0006 lifecycle)
  · AUDIT/VERIFY — its QC + Seed-Honor history
- **Wired to schema:** each hub carries its SCHEMA-00001 position; the SSOT-registry maps topic→hub
  (so the registry + the front-end front-end ARE the index of all hubs = the living index DNA-00001).
- **One SSOT:** the hub is THE single home for its topic; everything about it consolidates there (I10).
- **Reused, not recreated:** touching a topic attaches to its existing hub-tree; no duplicate trees.

**This unifies:** mini-tree (structure) + SSOT (one home) + Gem (concentration) + schema (position) +
discussions (persistent) + versions (BP-0006) — into ONE governing pattern.
